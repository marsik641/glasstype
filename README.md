# GlassType 0.2.2

Прозрачное окно с оригинальным https://monkeytype.com/ для Windows 10/11 (x64).

## Запуск

Готовые сборки размещаются в [Releases](https://github.com/marsik641/glasstype/releases). Скачайте архив сборки для Windows, распакуйте его целиком и откройте `GlassType.exe` внутри папки `GlassType-win32-x64`. Установка и Node.js для запуска готовой сборки не нужны. При переносе приложения сохраняйте все файлы рядом с `.exe`.

После локальной сборки из исходников можно открыть `dist/GlassType-win32-x64/GlassType.exe` или `Запустить.cmd` в корне проекта.

## Вход через ваш обычный Chrome

Кнопка **G** открывает официальный Monkeytype в обычном Chrome, с его текущим профилем. Новые пользователи Chrome и отдельные профили не создаются. Существующие вкладки остаются открытыми.

Для переноса входа в клиент один раз добавьте **GlassType Connect** в тот же профиль Chrome:

1. Откройте `chrome://extensions`.
2. Включите «Режим разработчика» справа вверху.
3. Нажмите «Загрузить распакованное расширение».
4. Выберите папку `GlassType Connect` рядом с `GlassType.exe`.
5. В GlassType нажмите **G**. Если вы уже вошли в Monkeytype, вход перенесётся автоматически. Иначе войдите на открывшемся официальном сайте.

Папку расширения также открывает кнопка «Папка расширения» на экране подключения. Выбор текущего окна и профиля при обычном открытии ссылки выполняет сам Chrome. При нескольких профилях расширение должно быть установлено в том, куда открывается ссылка.

Расширение работает только на `monkeytype.com`. Оно читает сессию только после нажатия G в клиенте и передаёт её локальному GlassType через временное соединение на 127.0.0.1 с одноразовым ключом. Пароли Google, cookies других сайтов и история браузера не читаются. Соединение прекращается после успешного переноса, отмены или через пять минут.

Вход по email/паролю остаётся доступен через исходный значок профиля Monkeytype; там отметьте **remember me**. Результаты и настройки аккаунта обслуживает сам Monkeytype.

## Управление

- **Ctrl+Shift+H** — показать или полностью скрыть верхнюю панель GlassType. В скрытом состоянии она не занимает место и не появляется при наведении. По умолчанию во время теста панель скрыта.
- **Ctrl+Shift+M** / **Текст** — скрыть или вернуть меню и настройки самого Monkeytype.
- **Tab** — перезапуск теста. Сначала клавишу обрабатывает сам Monkeytype; если он её не обработал, GlassType нажимает штатную кнопку перезапуска. В формах, диалогах и на других страницах Tab сохраняет обычную работу. Shift+Tab не переопределяется.
- **Ctrl+Shift+Space** — показать/сфокусировать или скрыть всё окно.
- **Ctrl+Shift+X** / **указатель** — пропускать клики в приложение под GlassType. Повторное нажатие возвращает управление.
- **Aa** — светлый текст, тёмный текст или исходные цвета темы.
- **Капля / проценты** — фон 0%, 20%, 45%, 80%. Текст остаётся непрозрачным.
- **Булавка** — поверх других окон.
- **Название GlassType** — перетащить окно. **Уголки** — выбрать размер. Нижний правый угол при видимой панели — произвольный размер.
- **Ctrl + / Ctrl − / Ctrl 0** — масштаб сайта. **Ctrl+R** — перезагрузка.
- **Минус** — скрыть окно; **крестик** — выйти из приложения.
- Значок рядом с часами — вернуть окно, панель или клики, изменить режим и выйти. Он доступен, даже если горячая клавиша занята другой программой.

При первом запуске, ошибке сети и подключении аккаунта панель видна для доступа к управлению. Клавиатурный ввод получает одно активное окно: при печати в Monkeytype другие приложения видны, но не получают те же клавиши.

## Данные и сеть

Нужен интернет и доступ к Monkeytype и его службам. VPN-расширение Chrome не действует на отдельный клиент: при необходимости нужен доступ на уровне системы.

Профиль сайта и настройки окна сохраняются в `%APPDATA%/GlassTape/`. GlassType не добавляет собственную аналитику и не меняет алгоритм теста. У сайта нет доступа к Node.js и управлению окном.

В версии 0.2.2 название исправлено с GlassTape на GlassType. Старое имя папки профиля и служебные идентификаторы подключения сохранены для совместимости: существующие аккаунт, настройки и установленное расширение продолжают работать. Переносить или удалять профиль не требуется.

Основной экран теста прозрачен. Страницы аккаунта, настройки и диалоги сохраняют читаемые подложки. Фоновые изображения Monkeytype скрыты ради прозрачности. При изменении разметки сайта косметические правила могут потребовать обновления. GlassType — независимая оболочка.

В 0.2.1 облегчено оформление при непрерывной печати, в том числе в режиме ленты с плавной прокруткой: убрана широкая размытая тень, а оформление страницы переключается при навигации вместо проверки содержимого на каждом кадре. Настройки анимации Monkeytype сохраняются.

## Разработка

Node.js 22.12+ и pnpm. После клонирования репозитория:

```text
pnpm install --frozen-lockfile
pnpm start
pnpm test
pnpm build
```

Сборка также подготавливает расширение GlassType Connect. Иконки включены в исходники. Chromium и лицензии его зависимостей находятся рядом с готовым приложением.

Перед пересборкой закройте приложение из выходной папки. Чтобы собрать отдельную копию при работающем клиенте, выполните `node scripts/package.cjs dist/release`; выходной каталог должен находиться внутри `dist/`.

В `src/` находится оболочка Electron, в `chrome-extension/` — расширение для Chrome, в `test/` — тесты, в `scripts/` — сборка и дополнительные проверки. Код самого Monkeytype загружается с оригинального сайта.

Проверки `scripts/check-*.cjs` и замер `scripts/profile-typing.cjs` дополнительно требуют Playwright; путь к его `package.json` передаётся первым аргументом скрипта. Тестовые профили и результаты создаются локально и исключены из Git. `check-package.cjs` проверяет собранное приложение с обычным профилем GlassType.

## Публикация сборки

1. Выполните `pnpm test` и `pnpm build`.
2. Упакуйте **всю папку** `dist/GlassType-win32-x64` в ZIP, например `GlassType-0.2.2-win32-x64.zip`. Отдельного `GlassType.exe` недостаточно: ему нужны соседние файлы Electron и Chromium.
3. В GitHub откройте **Releases → Draft a new release**, создайте тег `v0.2.2` на нужном коммите ветки `main` и укажите название `GlassType 0.2.2`.
4. Прикрепите ZIP к релизу и опубликуйте его. Сборку не нужно коммитить в репозиторий.

## Публикация исходников

В Git включаются исходники, иконки, документация и lock-файл зависимостей. Профили браузера, кэши, сборки, скриншоты и диагностические отчёты исключены через `.gitignore`. Перед отправкой проверьте `git status` и `git diff --cached`; не добавляйте исключённые файлы принудительно.

Данные аккаунта не входят в исходники и хранятся отдельно от приложения. Рекомендации по работе с ними — в [SECURITY.md](SECURITY.md).

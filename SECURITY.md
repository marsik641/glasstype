# Данные аккаунта и безопасность

GlassType открывает оригинальный Monkeytype. Сессия сайта хранится локально в
профиле Electron: `%APPDATA%/GlassTape/` на Windows. Тестовые профили находятся
в `.test-profile/`. Эти каталоги могут содержать действующие cookies и токены;
их нельзя прикладывать к коммитам, Issues или релизам.

Расширение GlassType Connect передаёт сессию Monkeytype в локальный клиент
только после запуска подключения пользователем. Для каждого подключения
создаётся случайный одноразовый ключ; сервер слушает только `127.0.0.1`.
Ключи и сессии не должны записываться в диагностические сообщения.

В исходниках нет необходимых для запуска приватных ключей или паролей.
Значения с префиксом `fake-` в тестах — вымышленные данные.

Перед публикацией проверяйте список подготовленных файлов (`git diff --cached`)
и историю коммитов сканером секретов, например Gitleaks. `.gitignore` исключает
профили, локальные настройки, диагностические файлы и типичные файлы секретов,
но не удаляет данные из уже созданных коммитов.

При обнаружении утечки сначала отзовите соответствующий токен или пароль,
затем удалите его из истории. Не вставляйте действующие учётные данные в
публичное описание проблемы. Для уязвимостей используйте приватное сообщение
об уязвимости GitHub, если оно доступно в разделе Security репозитория.

Лицензия MIT распространяется на код GlassType. Monkeytype, Electron, Chromium
и их зависимости распространяются на условиях собственных лицензий.
